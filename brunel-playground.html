02 · The input is stochastic

The network is driven by a Poisson background input. In the notebook, the mean external rate is derived from an input-level parameter and the thresholding scale of the network. The notebook also contains an optional sinusoidal modulation pathway for future experiments.

05 · Parameter sweep #2 — synaptic timescale

The project compared several τsyn values. The dominant frequency stayed relatively stable across the explored range, while the spectral peak became flatter as the synaptic time constant increased. At sufficiently high values, the presentation notes that neurons seemed less able to entrain as a network.

06 · Parameter sweep #3 — adaptation

Increasing adaptation strength reduced the output amplitude and shifted the population's preferred resonant frequency lower in the project simulations.

07 · A useful caveat

What this notebook currently computes: the main spectrum function runs the network under constant-rate stochastic Poisson drive, removes the mean population rate, and computes its FFT amplitude spectrum. The notebook also defines an optional sinusoidal modulation pathway, so a future experiment could directly compare an imposed oscillatory input with the network's emergent spectral preference.
